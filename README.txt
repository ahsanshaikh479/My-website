# APSIS Hyderabad — Static Bootstrap 5 Website

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Add your own images
Put your files in `images/` using these names:
- logo.png
- hero-1.jpg
- hero-2.jpg
- hero-3.jpg
- campus.jpg
- principal.jpg
- academic.jpg
- sports.jpg
- activity.jpg
- event-1.jpg
- event-2.jpg
- event-3.jpg

Gallery (event albums):
- images/gallery/<event-folder>/1.jpg, 2.jpg ... (edit the EVENTS list inside gallery.html to add or rename events)

If an image is missing, the browser will show a broken image icon; simply replace it with your own school photo using the same filename.

## Pages
Home, About Us, Academics, Campus Life, Gallery, News & Events, Contact Us.

No login, registration, database, or admin panel is included.
